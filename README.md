# Baba Ayurved Pharmacy: website

Premium, mobile-first website for Baba Ayurved Pharmacy (founded 1999), which carries forward Phoolchand Aushdhalaya, a family Ayurvedic practice in Madhya Pradesh, India, of more than 150 years. Positioning: **Ritual, not remedy.**

**Status: Phase 2, development preview.** The site is `noindex`, uses labelled placeholders wherever real assets or verified facts are missing, and is **not launch-ready**. See [docs/ASSET_READINESS.md](docs/ASSET_READINESS.md). Brand direction and decisions: [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md). Proposed next routes: [docs/SITEMAP_PROPOSAL.md](docs/SITEMAP_PROPOSAL.md).

## Stack

- Next.js 16 (App Router, Turbopack, Cache Components) with React 19 and TypeScript
- Tailwind CSS v4 (tokens in CSS, no `tailwind.config`)
- Motion for React (`motion`), used through `LazyMotion` and the small `m` elements
- ESLint (`eslint-config-next`, core-web-vitals and TypeScript rules)
- `next/font`: Source Serif 4, Archivo, Tiro Devanagari Hindi (self-hosted at build time)
- Lucide React for the few functional icons (text-link arrows). The brand visuals do not depend on it.

Requires Node 20.9 or newer. Developed on Node 20.11; npm prints engine warnings for some transitive ESLint packages that prefer 20.19 or newer. They do not affect lint or build.

> `AGENTS.md` is generated by Next.js and points coding agents at the version-matched docs in `node_modules/next/dist/docs/`. Next 16 differs from earlier versions: check those docs before using unfamiliar APIs.

### Principles

- **Server Components by default.** Client Components are limited to `MobileNav` and the motion helpers (`Reveal`, `Parallax`, `MotionProvider`). The hero is server-rendered and animates with CSS only, so it never waits on JavaScript.
- **Tokens first.** Colour, type scale, spacing, radii, borders and motion are CSS variables in `globals.css`, exposed as Tailwind utilities (`bg-indigo`, `text-hero`, `px-gutter`, `py-section`, `max-w-page`). The Tailwind default palette is removed on purpose so off-brand colours cannot appear by accident.
- **Content is data.** Rituals, categories, image slots and source records live in `src/content/`. Changing copy or adding an asset does not mean restructuring a page.
- **Tone surfaces.** `Section tone="paper" | "paper-deep" | "indigo"` sets `--tone-*` variables, so type components adapt to the surface without extra props.
- **Type rules are encoded.** `Heading` fixes the weight per size (400 for hero, display and statement; 500 otherwise), so the serif cannot exceed 500. Tracked caps appear only in Archivo labels and the wordmark.
- **Hindi.** `--font-serif` and `--font-sans` end in Tiro Devanagari Hindi so Devanagari falls back to Tiro, never a system font. Mark Hindi with `lang="hi"`. No Hindi is on the public pages yet because no approved wording exists.
- **Cache Components.** `params` is read inside `<Suspense>` on dynamic routes, as this Next version requires for instant navigation (see `rituals/[slug]/page.tsx`). Avoid reading the current time or request data in Server Components without `Suspense` or `use cache`.

### Motion language

One easing (`--ease-calm`), two speeds (200ms for state changes, about 0.9s for reveals). Content rises a short distance or opens like a clipped plate; nothing bounces.

- `Reveal` plays once on scroll. It tags itself `[data-reveal]`, and `globals.css` forces such elements visible when scripting is off or reduced motion is requested.
- `Parallax` drifts a large plate slightly against the scroll. It is switched off under reduced motion. **Nest it outside `Reveal`** (so the clipped element is the one that moves).
- `usePrefersReducedMotion` is hydration-safe (`useSyncExternalStore`).
- The slow turn of the sunray ornament (`spin`) is CSS and stops under reduced motion.
- Hover and focus responses are CSS transitions. Nothing essential is hover-only.

### The rosette and its surrounds

`<Rosette size color title variant strokeWidth />` draws the brief's seven-circle geometry from one unit radius. With `variant="auto"` it follows the brief's size ladder: full (32px and up), petal (20 to 32px), silhouette (14 to 20px), rounded hexagon (under 14px). It is a code construction, not the final vector mark.

`<RosetteSurround treatment="sunray" | "rays" | "halfmoon" />` adds the brand's own radial surrounds. They are **not Gond artwork** and never stand in for it.

### Images and artwork

No brand photography or Gond artwork exists in the repository. The site's image slots currently hold **real, temporary photography**, properly licensed from Wikimedia Commons (not generated, not stock misrepresented as the brand's own) and credited in `public/images/CREDITS.md`, so the homepage shows a finished composition rather than empty plates while brand photography is commissioned. `ImageFrame`'s `overlayLabel` prop prints a short, specific in-image credit (e.g. "The lota: the vessel for ushapan") naming what each photo actually shows. To replace a slot with real brand photography: put the file in `public/images/`, set `src`, real `alt` and `focal` in `src/content/assets.ts`, and set `temporary: false`. Boxes are sized by aspect ratio, so media never causes layout shift. An image slot with no `src` still renders a labelled, designed fallback rather than a blank box.

`ArtworkZone` accepts a commissioned Gond work only if **artist name, village and licence reference are all supplied**. It shows an empty labelled zone otherwise. Do not fill it with in-house imitation or generated imagery.

`ScrollRow` wraps a horizontal list in native CSS scroll-snap (no JavaScript, no carousel library) for touch-swipeable rows, used for the "by ritual" photo row on the homepage.
